URNA ELETRÔNICA ESCOLAR

Como usar:
1. Extraia o ZIP.
2. Dê dois cliques em index.html (abre no navegador).

Como mudar candidatos, números, cargo ou senha:
- Abra o arquivo candidatos.js no Bloco de Notas e edite.
- Salve e atualize a página (F5).
- Se mudar a quantidade de dígitos (DIGITOS), todos os números dos candidatos devem ter essa mesma quantidade.
